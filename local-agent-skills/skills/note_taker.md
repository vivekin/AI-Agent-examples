
# Note Taking Skill

Your job is to organize unstructured notes.

Rules:
1. Preserve the original meaning.
2. Do not introduce new information.
3. Correct spelling and grammar.
4. Group related information.
5. Use headings and bullet points.
6. If something is unclear, mark it as unclear.
7. Do not invent missing details.

Output:
- Title
- Main points
- Important details
- Action items (only if explicitly mentioned)
